# Staff

- [Agent Statuses](agent-statuses.md) — current agent working states, temporary transitions, history, and availability resolution.

Административный раздел Staff управляет агентами, ролями, отделами, командами и переиспользуемыми [Work Schedules](work-schedules.md). Work Schedules не изменяют `Department.business_hours` и пока не участвуют в автоматическом распределении тикетов.
